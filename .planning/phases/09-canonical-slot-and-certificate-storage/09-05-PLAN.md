## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public MintFunds arguments → UTXO/queue state | Caller-controlled chain/hash text can reserve state before consensus validation |
| Mint proposal → external RPC request | A zero or fallback source can remove the burn-proof requirement |
| RPC response → endpoint weight | A provider can return a valid-looking receipt for a different transaction |
