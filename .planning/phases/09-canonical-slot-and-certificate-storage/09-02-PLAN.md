<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EVM RPC receipt → bridge discovery | RPC indexes and logs are untrusted observation data |
| Bridge discovery → mint APIs | Event identity can be dropped or substituted during orchestration |
| Mint proposal → public-chain validator | Candidate-controlled outputs claim to represent an external burn |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02 | Spoofing / Tampering | Receipt index derivation and propagation | mitigate | Derive ordinal from full ordered receipt, carry a required typed value, deduplicate by tuple, and remove all zero defaults |
| T-09-03 | Tampering | `PublicChainInputValidator` | mitigate | Bounds-check and decode only the indexed log, then compare every event fact with the mint |
| T-09-08 | Denial of Service | Catch-up receipt fetch | mitigate | Cache per-transaction receipt inside a scan batch and fail closed on unavailable/inconsistent receipts |
</threat_model>
