<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator/provider writers → shared RPC configuration | Concurrent map rehash or lost update can corrupt verification policy |
| RPC snapshot → signed vote | Mixed endpoint generations can produce nondeterministic slot commitments |
| RPC snapshot → weighted receipt loop | Torn endpoint/factory state can change quorum during one decision |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-09-G16-01 | High | Tampering / Denial of Service | RPC configuration publication | mitigate | Serialized copy-on-write immutable snapshots with lifetime-owned readers |
| T-09-G16-02 | High | Repudiation / Tampering | Vote slot hashes | mitigate | One value-returning vote snapshot supplies chain and all three hashes from one generation |
| T-09-G16-03 | High | Spoofing / Tampering | Receipt quorum | mitigate | One retained snapshot supplies endpoint vector and transport factory for the complete decision |
| T-09-G16-04 | Medium | Denial of Service | Provider/operator merge | mitigate | Add merges onto the latest snapshot under writer serialization and preserves URL dedup/metadata upgrades |
</threat_model>
