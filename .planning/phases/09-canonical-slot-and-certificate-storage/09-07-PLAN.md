Add one private certificate normalization seam used by `CreateCertificate`, `SubmitCertificate`, `FilterCertificateDelta`, `FilterCertificate`, and authoritative lookup validation. It must return the existing `Check::Stalled` only for an unavailable registry dependency and otherwise either a normalized `Certificate` plus deterministic bytes or rejection.

Reject protobuf unknown fields recursively across the certificate and every nested message (proposal, subject/payload messages, embedded transaction, votes, and their nested fields) using protobuf reflection; do not call `DiscardUnknownFields` and accept the result. Require certificate/proposal IDs and registry fields to match existing derivations. Validate every serialized vote instead of silently skipping it: `proposal_id` must equal the certificate proposal, voter IDs must be unique, the voter must exist and be ACTIVE in the referenced registry, `VoteSigningBytes` must succeed, and the signature must verify. Valid approve=false votes may remain but receive no approved weight. Sort the full valid vote set by raw `voter_id()` bytewise ascending; uniqueness makes the order total.

Derive `total_weight` from `ValidatorRegistry::TotalWeight`, `approved_weight` from valid unique approving voters (while preserving the existing bridge slot-quorum evaluation), and certificate `timestamp` as the maximum timestamp of the canonical included votes. Remove the wall-clock fallback from `CreateCertificate`; reject a certificate with no valid votes/quorum. Local creation emits votes in canonical order and sets only these derived redundant fields. `SubmitCertificate` stores normalized deterministic bytes even if its in-memory input arrived in a different order.

For replicated data, parse the original slot bytes, normalize them, deterministically serialize the normalized certificate with `SerializeCertificateDeterministically`, and require exact byte equality with `slot_element->value()` before existing key/index/occupied-slot checks. Do not accept and rewrite noncanonical remote bytes. Make `GetCertificateBySlotId` also require stored bytes equal normalized canonical bytes so bypassed/corrupt local state reports `IntegrityError`.

Extend the two-validator certificate fixture and add direct pair-delivery cases for: top-level and nested unknown fields; changed timestamp; changed total and approved weight; reverse-ordered otherwise valid votes; duplicate voter; wrong-proposal vote; inactive/unknown voter; bad signature; and an appended invalid vote while remaining valid votes still satisfy quorum. Assert each remote delta makes neither v2 record visible. Add a canonical two-vote control and an honest deterministic replay control that remain byte-identical and idempotent.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote protobuf bytes → authoritative slot value | Equivalent semantics can have distinct wire bytes and first-write conflict behavior |
| Serialized vote list → quorum | Ignored or duplicated attacker-controlled votes can survive when honest quorum remains |
| Remote CRDT key → local `/cert/` state | Default acceptance can persist incompatible protocol keys |

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan |

| T-09-G07-01 | High | Tampering / Denial of Service | Certificate wire representation | resolved in-plan | Recursive unknown rejection, strict vote validation, normalization, exact deterministic byte comparison |
| T-09-G07-02 | High | Spoofing / Tampering | Certificate quorum surfaces | resolved in-plan | Reject every invalid/duplicate vote and derive weights/timestamp |
| T-09-G07-03 | High | Tampering / Denial of Service | Runtime `/cert/` namespace | resolved in-plan | Full-namespace delta guard plus restart regression |
| T-09-G07-04 | High | Tampering / Denial of Service | Authoritative slot/index tombstones | resolved across 09-07/09-08 | Certificate callback rejects every `/cert/` tombstone; Plan 09-08 makes tombstones participate in namespace matching and removes them before merge |
