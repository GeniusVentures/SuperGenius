<objective>
Build the block-storage half of the atomic erase and the revert-free tracked-map cleanup: `GraphsyncDAGSyncer::StageBlockRemoval` (the single SuperGNUS-side home of the vendored block-key contract, staging a raw delete into the caller's batch instead of executing the non-atomic `removeNode` chain) and `TransactionManager::RemoveProcessedTransactionEntry` (plain `tx_processed_m` erase — no `RevertTransaction`, no `RollBackPeerConfirmedNonce`, no `DeleteTransaction`). Purpose: PRUNE-02's one-WriteBatch atomicity is only achievable by staging the raw `CID::toBytes()` key into the shared batch — every layer of the dormant `removeNode` chain executes its own immediate `db->Delete` and cannot join an external batch (RESEARCH Pitfall 2). GATE-03 makes the seal marker unaddressable by construction. Pitfall 1 makes the tracked-map cleanup a plain erase.

Output: Modified DAGSyncer + TransactionManager sources, new unit test file + CMake link addition. Zero production behavior change — no production caller of either new method in this plan; `removeNode` stays dormant.
</objective>
