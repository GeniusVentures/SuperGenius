## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Reviewed manifest/key input to local tool | Human-reviewed trust and ephemeral secret enter the process. |
| Local tool to production CRDT | Explicit local intent becomes an authenticated candidate approval. |

| Threat ID | Category | Component | Disposition | Mitigation Plan | Automated verification |
|-----------|----------|-----------|-------------|-----------------|------------------------|

| T13-02 | Information Disclosure | ephemeral key | mitigate | stdin/0600 no-symlink file only, in-memory signer, no account storage/logging, cleanse, success-only unlink. | argv/log/storage/deletion tests |
| T13-04 | Tampering | admin approval | mitigate | Exact candidate ID/bytes and explicit command; receive path cannot sign. | local admin spy test |
