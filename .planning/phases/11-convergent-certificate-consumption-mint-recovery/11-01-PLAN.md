<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CRDT callback → committed certificate recovery | Callback data is pre-commit and cannot authorize finality; durable canonical readback is required. |
| Consensus startup → later TransactionManager handler registration | A valid durable certificate can predate its local consumer and must remain replayable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Denial of service | `ProcessCommittedCertificate` no-handler branch | mitigate | Mark valid committed work Stalled, then trigger `RecoverPendingCertificateWork` after successful handler registration; regression proves one post-registration dispatch. |
| T-11-01b | Tampering | certificate callback / work journal | mitigate | Preserve canonical `/cert/<slot>` committed readback plus parse, key, quorum, and exact binding validation before release or dispatch. |
</threat_model>
