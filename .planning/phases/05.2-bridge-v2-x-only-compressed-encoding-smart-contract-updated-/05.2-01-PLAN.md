From RESEARCH.md Byte Ordering Reference:
- Contract bytes32 X: 32 bytes in reverse order (LSB first in hex)
- libsecp256k1 expects big-endian (MSB first)
- Must reverse contract bytes before prepending 02/03 prefix
- After decompress: extract Y_bigendian (bytes 33..64 of 65-byte uncompressed), reverse to contract order
- Destination = hex_bytes(contract_X, 32) + hex_bytes(contract_Y_reversed, 32) → 128 hex chars
