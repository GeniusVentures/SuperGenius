    **Part A: Add PerformStartupCatchupScan()**

    In GeniusNode.hpp, add `void PerformStartupCatchupScan()` private method and `bool catchup_scan_done_ = false` member.

    Trigger: In TransactionStateChanged() at line 2011, case TransactionManager::State::READY (after CRDT sync complete):
    ```cpp
    if (!catchup_scan_done_) {
        catchup_scan_done_ = true;
        boost::asio::post(io_, [weak_self = weak_from_this()] {
            if (auto self = weak_self.lock()) self->PerformStartupCatchupScan();
        });
    }
    ```

    **Part B: Implement scan body**

    1. Guard: if !transaction_manager_ or !bridge_relayer_, return.
    2. Get last mint timestamp/block from TransactionManager. If no prior mints, default to 0.
    3. **Scan depth:** Default 10,000 blocks (~2 days mainnet). Add `bridge_catchup_scan_depth` field to `DevConfig` (uint64_t, default 10000). Cap scan at `max(last_mint_block - scan_depth, 0)`.
    4. For each chain with bridge_contract_address:
       - Construct `eth_getLogs` request: address=bridge_contract_address, topics[0]=event_topic0, fromBlock=hex(from_block), toBlock="latest"
       - Send RPC request via RpcHttpTransport per RPC URL (or reuse existing RPC client)
       - Parse response for burn event logs
       - For each burn event:
         a. Extract tx_hash from log
         b. Check if UTXO already exists (by burn_tx_hash or UTXOType::UTXO_BRIDGE query)
         c. If NOT found: insert as READY with `UTXOType::UTXO_BRIDGE` via `MintFunds()` or `PutUTXO()`
         d. If RESERVED: log and skip (already in consensus)
         e. If CONSUMED: log and skip (already processed)
    5. **RPC timeout:** 10 seconds per call. Failure on one chain → log warning, continue (best-effort).
    6. Log summary: "CatchUpScan: found N historical burns across M chains"

    **RPC transport:** Catch-up scan needs its own transport. Use direct RpcHttpTransport construction per chain's RPC URL from the provider. Check evmrelay for `eth_getLogs` helpers; if none, construct JSON-RPC request manually with boost::json::object.

    **DevConfig:** Add `uint64_t bridge_catchup_scan_depth = 10000` for production configurability.
