## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| block bytes → gate | delta blocks deserialize at evaluation time; a corrupt block must fail closed (not erasable) |
| marker bytes → lookup | marker records decode from the raw surface; malformed records must not crash or masquerade as PRUNED |
| marker key space → value presence | the PRUNED verdict depends on marker∧¬value; both reads must go through the same resolution path |
