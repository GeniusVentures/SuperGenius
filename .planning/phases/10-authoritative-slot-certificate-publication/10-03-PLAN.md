<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| consumer lookup argument → certificate record | Caller-supplied slot selects durable authority and must not alias an arbitrary hash. |
| CRDT value → API result | Stored bytes must still be bound and quorum-valid before the facade returns them. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-10-01 | Spoofing | lookup identity | mitigate | D-11: only `/cert/<canonical-slot>` is queried; subject hashes never confer authority. |
| T-10-04 | Tampering | stored certificate lookup | mitigate | Parse, quorum validate, and compare the requested key with `GetExpectedCertificateSlotKey` before returning data. |
| T-10-05 | Denial of service | missing/malformed lookup | mitigate | Return an outcome failure/false to preserve retryable unavailable behavior; do not fall back to legacy hash records. |
| T-10-SC | Tampering | package installs | mitigate | No package installs; existing project facilities only. |
</threat_model>
