## Trust Boundaries

| Boundary | Description |
|---|---|
| transaction hash → CRDT transaction | A hash identifies a transaction retrieval request, not finality authority. |
| recovered transaction → slot certificate lookup | Stored transaction identity supplies the canonical slot used to read the certificate. |

| T-10-04 | Tampering | recovered certificate | mitigate | Consume Plan 10-03's binding-validating slot lookup API only. |
