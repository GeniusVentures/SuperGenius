<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| quorum state → publisher path | Local candidate evidence may produce a durable authority record only under protocol-selected authority. |
| PubSub message → consensus handler | Peer-delivered certificates are untrusted notifications, not write authority. |
| CRDT callback → recovery | Callback is pre-commit and cannot prove durable acceptance. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-10-01 | Spoofing | ProcessCertificates publisher selection | mitigate | D-01/D-02: gate the write path on existing `CurrentAggregator`; do not use delivery source or receiver state. |
| T-10-02 | Elevation of privilege | HandleCertificate/PubSub receipt | mitigate | Keep receipt keyless and validation-only; tests assert it never calls immutable Put. |
| T-10-03 | Tampering | SubmitCertificate ordering | mitigate | Validate, collision-check, and durable immutable Put before a single full-certificate notification. |
| T-10-04 | Tampering | occupied `/cert/<slot>` | mitigate | Use Plan 10-01 immutable semantics; exact replay is idempotent and differing/malformed/unreadable occupancy fails closed. |
| T-10-06 | Repudiation | best-effort notification | mitigate | Log every observable publish failure, expose a narrow deterministic failure seam, and assert no retry is scheduled. |
| T-10-07 | Tampering | pre-commit CRDT callback | mitigate | Callback only journals stalled work; committed readback/recovery is the sole completion path. |
| T-10-SC | Tampering | package installs | mitigate | No package installs; use existing C++17/CMake/GoogleTest/RocksDB/CRDT/PubSub facilities. |
</threat_model>
