## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test fixture → ConsensusManager/TransactionManager | Friend-only test synchronization reaches production internals; it must never become an authority or delivery API. |
| real peer transport → consensus/CRDT/Mint | Untrusted/reordered protocol input must continue through normal validation, durable readback, and exact-Mint binding. |
| peer runtime → persistent root | Restart exposes partially durable vote, certificate, UTXO, and marker state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | E/T | `MultiNodeFinalityFaultTestAccess` in Consensus and TransactionManager | mitigate | Friend-only access can arm/release/read post-action counters and barriers only; no public API or methods for handler invocation, datastore writes, timer forcing, selection, message creation, or delivery. |
| T-12-02 | T | Certificate persistence/notification boundary | mitigate | Count and optionally pause only after successful `PutConvergentImmutable` and before unchanged `Publish`; failed writes cannot advance the seam. |
| T-12-03 | T/D | Mint durable completion boundary | mitigate | Observe/block only after successful UTXO-producing `ParseTransaction` and before existing marker persistence; test restarts use the retained storage rather than fabricated results. |
| T-12-04 | S/T | Four-peer harness ingress | mitigate | Use real `GossipPubSub`, `GlobalDB`, public proposal submission, and bounded observation; negative source gate forbids direct receive/author and transport mocks. |
</threat_model>
