<objective>
Close the Phase 12 harness-ownership gap exposed by an interrupted real-socket run, without changing any finality behavior.

Purpose: Ordinary `Peer::Stop()` completion already releases 54631-54634. The remaining defect is runner cancellation: the top-level GTest or its collector's fork/exec descendant can survive a cancelled parent and retain those fixed ports. CTest must own a narrow process boundary that can terminate and account for exactly the processes it started.
Output: A dedicated POSIX CTest launcher and a self-cleaning cancellation/reap regression for the existing real-socket PublisherLoss collector path.
</objective>

    On a handled cancellation signal, or on the dedicated regression path, invoke one shared `TerminateOwnedGroup(child_pid, pgid)` routine only after the handshake proves `child_pid == pgid`, `pgid > 1`, and the group/session is not the runner's. Reap the direct child with `waitpid`; then require a group-existence probe `kill(-pgid, 0)` to fail specifically with `ESRCH`. Treat `EPERM`, a changed group/session, an invalid PID, a missing direct-child status, or any other result as a failed-closed ownership error. The runner must never target PID 0, its own process group, a positive process name, a discovered unrelated PID, or a parent/session not created by this invocation. Preserve the child exit status for ordinary runs; cancellation verification may return success only after its explicit cleanup checks pass.

If all four do not become ready before the runner's own bounded diagnostic deadline, terminate/reap the exact owned group and fail with the observed port set. Once ready, call the same exact-group termination routine, then re-bind each fixed loopback port as the final reuse proof. The self-test succeeds only if the direct GTest parent is reaped, the inherited collector child group has vanished, and all four ports rebind; it must not interpret GTest signal termination itself as a product failure.

    Add an explicit runtime platform preflight before either mode: validate the POSIX APIs and errors used above, the readiness pipe, `fork`, `setsid`, `getpgid`, `getsid`, `kill`, `waitpid`, signal waiting, `socket`, `bind`, and loopback connect. Compile guarded code only on the platform family approved by Task 2. Any unsupported primitive or ambiguous return emits `P12_PROCESS_OWNERSHIP_PREFLIGHT=failed reason=<exact-reason>` and exits nonzero; no shell- or timer-based workaround is permitted.
