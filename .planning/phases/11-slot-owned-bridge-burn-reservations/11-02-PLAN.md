<threat_model>
## Trust Boundaries

| Boundary | Risk |
|---|---|
| Canonical proposal identity to durable keys | Alias or collision can create two owners for one burn |
| Async cleanup to deleted/recreated state | ABA can unlock a fresh reservation |
| RocksDB bytes to runtime safety state | Corruption can silently reopen finalized resources |
