<threat_model asvs_level="1" block_on="high">
## ASVS L1 Trust Boundaries

| Boundary | Risk |
|---|---|
| Consensus state to test observer | Re-entrant or blocking observation can perturb consensus timing or deadlock a state lock |
| Signer/publication path to diagnostic event | Diagnostics can misclassify replay, omit a target, or expose sensitive signing material |
| Node ownership graph to friend accessor | Test access can widen lifetime or mutation authority into production APIs |

## STRIDE Threat Register

| Threat ID | Severity | Category | Mitigation |
|---|---|---|---|
| T-12-01 | High | Denial of Service / Tampering | Per-instance callbacks run after locks are released, have no return value, and cannot alter persistence/publication outcomes |
| T-12-02 | High | Spoofing / Repudiation | Events bind validator, canonical slot, proposal, winner, and deterministic public digest; exact replay compares equal and different targets compare unequal |
| T-12-06 | Medium | Information Disclosure | Events exclude private keys, seeds, secure storage, and unsigned signer payloads |
| T-12-07 | Medium | Tampering | Per-instance hooks and RAII cleanup prevent cross-test/global contamination; friend access copies existing shared ownership only |

Every High threat is blocked by automated focused tests before Plan 12-04 consumes the observer.
</threat_model>
