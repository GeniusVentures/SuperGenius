<objective>
Land the D-01 substrate: a consumed-preserving clear API in UTXOManager (the lifecycle owner) so that a later checkpoint-mismatch rebuild can never resurrect spent outputs. Today `SetUTXOs({}, address)` wipes CONSUMED entries and their `spent_by_txid` evidence, and `StoreUTXOSnapshot` replaces the `/utxo/` prefix — the root cause of the double-spend window this phase closes (per D-01, 19-RESEARCH finding 1).

Purpose: The owner-vended preserve discipline is the by-construction resurrection blocker; `PutUTXO`'s existing duplicate check (UTXOManager.cpp:166-172) becomes load-bearing once CONSUMED entries survive.
Output: `UTXOManager::ClearUnspentKeepConsumed` + KeepConsumed unit suites.
</objective>
