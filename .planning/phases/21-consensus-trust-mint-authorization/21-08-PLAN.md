| Boundary | Description |
|----------|-------------|
| gossip/RPC submitter → PublicChainInputValidator | Untrusted mint transactions cross here; the submitter controls outputs count, values, and source_reference |
| RPC endpoint config → quorum assembly | Endpoint operator / merged endpoint lists control bridge_contract_address and accepted_topic0_hashes; a mis- or un-configured endpoint must not become an authorization oracle |
| public-chain RPC → evidence | Honest-but-unrelated receipts cross here; receipt existence alone must not attest a burn |
