## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Retained caller to `TransactionManager` | A stale `shared_ptr` crosses from lifetime-safe ownership into mutation-capable public APIs after account retirement. |
| `GeniusNode::SelectAccount` to manager lifecycle | Node switch acceptance must close old-manager admission before success is externally observable. |
| Async transaction/network continuation to terminal ledger | Callbacks may mutate only an operation admitted under the old generation and must not create new drain work after closure. |
| Manager lifecycle locks to io/callback execution | Reentrant callbacks and posts cross from protected state into arbitrary asynchronous code and must execute only after unlock. |
