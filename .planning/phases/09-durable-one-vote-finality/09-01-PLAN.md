<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| validated proposal → local slot state | Candidate timing and identity become input to one-vote arbitration. |
| ConsensusManager → local RocksDB | A signed vote becomes durable private safety state. |
| local recovery/timer → PubSub | Stored signed bytes are replayed across crash and transient send failure. |
| accepted certificate ingress → active-vote lock | A certificate event may later release a permanent no-revote lock. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | `ActiveVoteRecord` read/recovery | mitigate | Parse fail-closed; recompute canonical slot, verify proposal/vote coherence and original signature; corrupt records never reannounce or unlock. |
| T-09-02 | Tampering / Repudiation | `PersistOrLoadExactActiveVote` | mitigate | Under `proposals_mutex_`, allow an existing slot key only when the complete encoded record is byte-identical; reject replacement without put, publish, or self-handle. |
| T-09-03 | Replay | `ProcessDueVoteWork` | mitigate | Compare persisted absolute deadline before every retry; replay only parsed stored signed bytes while strictly before it, then retain the durable lock and prohibit fresh voting. |
| T-09-04 | Tampering | certificate release integration | mitigate | This plan establishes no release on receipt, parse, `HandleCertificate`, or volatile cleanup; Plan 02 releases only after durable accepted same-slot evidence. |
| T-09-05 | Denial of Service / Race | candidate admission and deadline freeze | mitigate | Enforce fixed two-second deadline under the slot mutex at admission and due work; freeze one eligible winner with existing deterministic ranking, ignoring late/stalled/nonwinner candidates. |
| T-09-SC | Tampering | dependency supply chain | accept | No package-manager installation or new dependency is permitted in this phase. |
</threat_model>
