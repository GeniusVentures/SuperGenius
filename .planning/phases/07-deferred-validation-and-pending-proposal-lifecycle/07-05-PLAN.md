<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| peer proposal -> ConsensusManager | Untrusted remote proposal data enters local validation and pending storage. |
| dependency event -> pending retry | Local CRDT/certificate arrivals wake pending proposals and can trigger repeated validation. |
| ConsensusManager -> TransactionManager cleanup | Local expiry/certification callbacks change transaction tracking state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Denial of Service | pending proposal pool | mitigate | TransactionManager returns dependencies only; ConsensusManager capacity limits from Plan 03 control storage. |
| T-07-02 | Denial of Service | retry scheduler and dependency wakeups | mitigate | Missing predecessor certificates produce typed dependencies processed by Plan 04 throttled retry, not local polling loops. |
| T-07-03 | Tampering / Elevation of Privilege | local Approval vote retry path | mitigate | TransactionManager never emits Approval votes directly; successful retry returns Approve through the handler result only. |
| T-07-04 | Tampering | dependency key indexing | mitigate | Missing predecessor certificates use typed `Certificate(previous_hash)` keys, preventing collision with unrelated dependency classes. |
| T-07-05 | Repudiation / Integrity | transaction state on inconclusive expiry | mitigate | Add UNCONFIRMED for inconclusive local expiry and preserve FAILED only for proven invalid transactions per D-13 and TXSTATE-01. |
</threat_model>
