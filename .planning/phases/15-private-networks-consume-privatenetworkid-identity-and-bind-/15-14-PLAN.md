Close CR-G01 (REVERIFICATION gap 1, blocker): the four membership gates currently authorize on the
UNAUTHENTICATED gossip from-field / protobuf-declared peer. Replace the authorization basis with an
AUTHENTICATED sender identity: private-network publishers seal gossip payloads with the same
libp2p keypair that constructs their gossip host, and every gate verifies the embedded public key
against the PeerId derived from the from-field plus a signature over the payload BEFORE consulting
membership. Fail-closed on missing/invalid envelopes under a set filter. Flip both production
gossip sites to sign_messages = true. Forged-from scenes (spoofed from + wrong/no signature) must
FAIL the gate.

section 3) is currently enforceable only against honest peers; this plan makes it effective against
the active adversary it was built for (PSK-holding non-member forging identity fields).

forged-from regression proofs.

## DESIGN CONSEQUENCE (the load-bearing decision)

Gossip-layer signature verification CANNOT be implemented from SGNUS without vendored
modifications (prohibited). The owner-sanctioned equivalent authenticated mapping is
APPLICATION-LAYER PAYLOAD AUTHENTICATION:

- Publishers seal gossip payloads into an envelope signed with the SAME keypair that constructs
  the gossip host, so PeerId::fromPublicKey(embedded key) == the from-field the vendored gossip
  stamps == the identity carried in NetworkRegistry membership records.
- Gates verify: envelope present -> unmarshal embedded public key -> PeerId::fromPublicKey ==
  PeerId::fromBytes(from) -> signature verifies over the canonical signable bytes -> ONLY THEN
  run the existing membership predicate on the authenticated PeerId. Any failure = deny
  (fail-closed, mirroring the empty-from denial).
- Wire format changes ONLY inside private networks (seal exactly when a filter is installed);
  public nodes publish raw and pass through raw (byte-identical).
- Additionally flip sign_messages = true at both production sites per the owner direction: it
  adds gossip-layer wire signatures for any future vendored verification and aligns production
  with the test fixtures (GetDefaultConfig already defaults true — gossip_pubsub.hpp:287-295).
  Document in-code that SGNUS gates do NOT consume these fields (fact 7).
