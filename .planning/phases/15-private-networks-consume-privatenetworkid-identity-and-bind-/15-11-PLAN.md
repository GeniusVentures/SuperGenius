<objective>
Close VERIFICATION.md gaps 1, 2, 4 (the enforcement-at-upgrade cluster) at the component level by
implementing the owner-directed replacement (deferred-items.md §3, BINDING):

> peer/membership filtering happens at the SuperGenius application layer ... at message-handling/
> peer-evaluation points ... consulting the NetworkRegistry's cached membership (its
> GetCurrentPeers() PeerId set), rather than at connection upgrade inside libp2p.

This plan builds the filter component and enforces it at THE single chokepoint where every
gossip message enters SGNUS CRDT replication: `PubSubBroadcasterExt::OnMessage`
(src/crdt/globaldb/pubsub_broadcaster_ext.cpp:127-204). All replicated data — chain elements,
network-registry updates, task/result CRDT entries, the SecureCrdt topic — flows through this one
handler (it is the only GossipPubSub subscriber in the crdt layer; verified this planning pass).

Design (per gap truth: "message/flow level, not connection-upgrade level"):
- A fail-closed predicate `MembershipFilter = std::function<bool(const libp2p::peer::PeerId &)>`
  built from a `weak_ptr<NetworkRegistry>`: expired registry → deny; empty GetCurrentPeers() →
  deny; else base58 membership test. The 15-05 fail-closed posture is preserved: empty membership
  never fails open.
- The broadcaster gets Set/Has/ClearMembershipFilter; OnMessage drops messages whose SGNUS-declared
  protobuf peer (bmsg.peer().id(), the existing peerId derivation at :146-157) OR whose transport
  `from` field (Gossip::Message::from, a ByteArray — convert via PeerId::fromBytes) is not an
  authorized member. Checking BOTH fields defends against spoofing either one; the declared peer
  is always set by SGNUS Broadcast(), `from` is populated because production gossip config runs
  sign_messages=true (test/src/pubsub_counts/pubsub_counts.cpp:50-58 documents this as the
  production default). The from-field check runs whenever a filter is installed — an EMPTY or
  unparseable `from` fails PeerId::fromBytes and is denied (fail-closed), matching the 15-13
  processing-path gates (checker round 3, context_compliance: no from-emptiness skip branch).
- No filter installed → pass-through (public nodes byte-identical behavior).

Purpose: an unauthorized same-PSK peer can mesh at the transport layer (pnet only proves
credential possession) but can no longer PARTICIPATE — its writes never enter any member's
replicated state. Output: filter component + broadcaster enforcement + unit and three-node
flow proofs.
</objective>
