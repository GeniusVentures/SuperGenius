Test fixtures force hash preference toward the uncertified loser, assert the intended tracked/CRDT preconditions, reject a borrowed certificate before legitimate ingress, and check the actual hold spender, all three recipient UTXOs/amounts/tokens, each recipient balance, both absent loser outputs and duplicate delivery.

## Decisions Made

- Keep source and nonce in the signed envelope and in ordinary account continuity even when a transaction type supplies a shared canonical slot.
- A shared canonical lookup can return the winner's certificate for a loser. Exact CertificateMatchesTransaction remains mandatory before treating that loser as certified finality.
- Preserve callback application-before-cleanup ordering so a rejected historical payload cannot demote valid contenders. Direct fetch and CRDT new-element paths obtain immutable exact canonical application evidence before conflict mutation.
- Reuse ChangeTransactionState and the existing guarded V2 rollback. No settlement store, quarantine, consensus special case, assignment policy or general input lock was introduced.
