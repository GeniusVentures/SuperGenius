# Phase 04.1 Plan 03: Catchup Watcher RPC Strategy Fix Summary

Replaced `scan_depth` (capped 10000-block lookback) with `start_block` (genesis scan, test-injectable), added exponential-backoff retry to `RpcHttpTransport::call()` so transient RPC failures no longer lose entire scan chunks, and corrected the Sepolia fallback URL to an archive-capable endpoint.

## What Was Built

### Task 1: scan_depth -> start_block field swap (D-19, D-20)
- `BridgeCatchupWatcher::Config` now has `start_block` (default 0 = genesis) instead of `scan_depth` (10000).
- `poll_once()` first-poll branch assigns `from_block = config_.start_block` instead of the `(current_block - scan_depth)` clamp.
- `startWatching()` log reports `start_block` instead of `scan_depth`.
- `kBridgeCatchupScanDepth` constant removed from `GeniusNode.hpp`; its assignment in `GeniusNode.cpp` removed (production uses the Config default = genesis).
- Subsequent polls still resume from `last_block_per_chain_` unchanged.

### Task 2: Exponential backoff retry in RpcHttpTransport::call() (D-23 Approach A)
- `RpcHttpTransportOptions` gained `retry_count` (default 3), `retry_backoff` (default 1000ms), and `kMaxRetryBackoffMs` cap (8000ms) as `static constexpr unsigned int` constants.
- New `CallOutcome` enum (`kSuccess` / `kTransientFailure` / `kPermanentFailure`) classifies each attempt's outcome.
- New `classify_http_status()` helper: 4xx = permanent (bail immediately), 5xx = transient (retry), 2xx/3xx = success.
- `read_https_response()` and new `attempt_http()` helper now return `pair<optional<string>, CallOutcome>`.
- `call()` wraps both HTTPS and HTTP paths in a bounded retry loop: `base * 2^attempt`, capped at `kMaxRetryBackoffMs`, using `boost::this_thread::sleep_for` (matches `bridge_catchup_watcher.cpp` pattern).
- `HttpsGet()` remains single-attempt (Option A, D-23) — documented in its Doxygen comment.
- Public `call()` signature is unchanged (`[[nodiscard]] std::optional<std::string> call(const boost::json::object&) override`).

### Task 3: Sepolia fallback URL fix (D-03)
- `kSepoliaRpcPublicnode` in `anvil_fixture.hpp` changed from `https://ethereum-sepolia-rpc.publicnode.com` (returns 403 on archive queries without a token) to `https://sepolia.drpc.org` (archive-capable, no API key).
- Constant name unchanged (`kSepoliaRpcPublicnode`) to avoid a cross-file rename — referenced by `SepoliaForkUrl()` and downstream test files.
