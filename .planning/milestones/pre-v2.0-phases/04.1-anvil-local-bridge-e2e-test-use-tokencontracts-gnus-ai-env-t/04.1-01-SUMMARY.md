# Phase 04.1 Plan 01: Anvil Local Bridge E2E Test Summary

Self-contained local-Anvil burn-to-mint E2E test that forks Sepolia state, funds Anvil default account #0 with GNUS via `anvil_impersonateAccount`, drives the bridge burn through `cast send`, and verifies the full BridgeRelayer → MintTokens → UTXO pipeline — plus a Sepolia-direct fallback test gated by `RUN_E2E_BRIDGE` + `PRIVATE_KEY` for the original Phase 4 live-testnet path.

## What Was Built

### Task 1: `test/src/bridge_e2e/anvil_fixture.hpp` (471 lines)
Header-only helper in `namespace sgns::test::anvil`:
- **`AnvilProcess` class** — RAII subprocess manager. `Start()` forks+execlps `anvil --fork-url <sepolia> --port <18545> --mnemonic <kAnvilMnemonic>`, redirects child stdio to `/dev/null`, returns false on fork/exec failure. `WaitForReady()` polls `cast block-number --rpc-url` via the global `waitForCondition` (no `sleep_for`). `Stop()` SIGTERMs + `waitpid`s. Destructor calls `Stop()` if started (crash safety net).
- **Inline constexpr constants** — `kAnvilMnemonic`, `kAnvilAccount0Address`, `kAnvilAccount0PrivateKey`, `kAnvilStartPort` (18545), `kAnvilReadyTimeoutMs` (15000), `kSepoliaChainId` ("11155111"), `kSepoliaBridgeContractLower`, `kBridgeEventTopic0`, `kGnusHolderSepolia` (0x910bAa33DeB0D614Aa9d80e38b7f0BF87549c2fC).
- **Free helpers** — `CastAvailable`, `AnvilAvailable`, `SepoliaForkUrl` (RPC_SEPOLIA override → default publicnode), `ParseTxHashFromCastJson` (Phase 4 lookup pattern), `RunShellCapture`, and `FundAccount0WithGnus` (impersonate holder → ERC-20 `transfer(address,uint256)` of 1e18 → stop impersonating → verify non-zero `balanceOf`).
- **Reused Phase 4 popen wrapper** — `OpenCommandPipe`/`CloseCommandPipe` copied verbatim as `static inline` (the established test-side `_WIN32` popen/_popen pattern; no new OS guards introduced).

### Task 2: `BridgeAnvilE2ETest` fixture + positive pipeline test
`test/src/bridge_e2e/bridge_anvil_e2e_test.cpp` (partial — Task 2 portion):
- **`BridgeAnvilE2ETest`** — 3-node fixture. `SetUpTestSuite` sets MemorySecureStorage factory, guards on `AnvilAvailable()`/`CastAvailable()` (GTEST_SKIP with Foundry install URL per D-16), resolves fork URL, starts Anvil, polls readiness, funds account #0 (GTEST_SKIP on funding failure per D-10), creates the full node first with the Anvil default key, sets authorized address, waits for READY, creates two processor nodes (ports 40012/40013), bootstraps PubSub, and calls `ConfigureRpcEndpoint` with a single endpoint pointing at the LOCAL Anvil instance (weight 100, satisfies the >= 75 consensus threshold per D-11).
- **`AnvilBurnToMintPipeline`** — sends an ERC-1155 `safeTransferFrom` self-transfer burn via `cast send --json` to the local Anvil RPC, parses the tx hash, calls `MintTokens`, and asserts balance increases by >= `kMintAmount` within `kMintTimeout` via `EXPECT_WAIT_FOR_CONDITION` (D-17a).

### Task 3: Replay rejection + Sepolia-direct fallback + CMake target
Appended to `bridge_anvil_e2e_test.cpp`:
- **`AnvilReplayRejection`** — fresh cast burn to local Anvil, first `MintTokens` succeeds, second `MintTokens` with the SAME tx hash is rejected (D-18). Asserts `second_result.has_error() || balance unchanged`.
- **`BridgeSepoliaDirectFallbackTest`** — self-contained 3-node fixture reproducing the original Phase 4 live-Sepolia path. Gated by `RUN_E2E_BRIDGE` + `PRIVATE_KEY`/`SIGNING_KEY` env vars (D-14 Path B). Uses a file-local `NormalizePrivateKey()` helper (Base64Decode + BytesToHex copied from Phase 4 to avoid symbol collision). Configures 6 live Sepolia RPC endpoints (weight 25 each, total 150). `BurnToMintPipeline` test mirrors Phase 4 exactly. Skips cleanly when env vars are absent.

`test/src/bridge_e2e/CMakeLists.txt` — appended a third `addtest(bridge_anvil_e2e_test ...)` block mirroring the `bridge_e2e_test` block: links `genius_node_test` + `json_secure_storage`, includes `${AsyncIOManager_INCLUDE_DIR}`, and copies the three-platform whole-archive link-options block (WIN32 `/WHOLEARCHIVE`, APPLE `-force_load`, else `--whole-archive`/`--no-whole-archive`).
