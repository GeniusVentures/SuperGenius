<objective>
Implement three UTXO subsystem changes required for bridge burn tracking: (1) Remove 8 foreign-address guards so all nodes store UTXOs for all peers per D-17 (REQ-UTXO-01), (2) Add UTXO_RESERVED lifecycle state for burn UTXOs during consensus voting per D-18 (REQ-UTXO-02), (3) Add UTXOType enum to distinguish bridge/burn UTXOs from regular UTXOs per D-19 (REQ-UTXO-03).

Purpose: Enable validators to track burn UTXOs from all peers for conflict detection, provide a RESERVED intermediate state so burn UTXOs are locked during consensus but not yet consumed, and mark burn UTXOs with a type flag for efficient startup catch-up scans.

Output: Updated UTXOManager with guard removal, new enum values, and type-tagged UTXO entries.
</objective>
