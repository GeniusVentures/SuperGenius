<objective>
Update `GeniusNode::PerformStartupCatchupScan()` to query BOTH v1 (`BridgeSourceBurned`) and v2 (`BridgeOutInitiated`) event topic0 hashes during the startup historical burn backfill (D-11, D-12). For v2 logs, decompress the 32-byte X-only key to a full 128-char destination before calling `MintFunds()` (D-13). V1 log processing is preserved unchanged. The decompression utility from Plan 01 is consumed here.

Purpose: When a node restarts after the v2 contract upgrade, it must backfill both v1 and v2 historical burns. Without this change, v2 burns emitted after the contract upgrade would be silently missed during catch-up, leaving UTXOs that should be minted unprocessed.

Output: GeniusNode catch-up scan queries both event versions and correctly processes v2 logs through decompression.
</objective>

    In `src/account/GeniusNode.cpp`, inside the v2 log processing block of `PerformStartupCatchupScan()` (the helper lambda / inline loop for v2 logs):

    **Step 1 — Extract X-only key from v2 log:**
    The catch-up scan receives raw `eth::codec::LogEntry` objects from `eth_getLogs`. The v2 contract event `BridgeOutInitiated` has: sender (indexed=true), id/amount/srcChainID/destChainID/sgnsDestination (all indexed=false). Indexed params are in `log.topics[1..N]`; non-indexed params are ABI-encoded in `log.data`.

    The `sgnsDestination` is param index 5 (0-based), which is the 5th non-indexed param. For the ABI decoding, use `eth::abi::decode_log_data(log.data, params)` where params are the non-indexed parameters only. But since the catch-up scan currently does raw `eth_getLogs` (not through the EthWatchService ABI decoder), it needs to either:
    - a) Use `eth::abi::decode_log_data()` directly with the v2 non-indexed params
    - b) Manually extract bytes from `log.data` at the known ABI offset

    **Recommended approach:** Use the existing `eth::abi::decode_log_data()` function. The v2 event has params[0]=sender (indexed), so non-indexed params are params[1..6]: {kUint "id", kUint "amount", kUint "srcChainID", kUint "destChainID", kBytes32 "sgnsDestination", kBool "destinationYOdd"}. The 5th non-indexed param (offset 4) is the bytes32 X-only key; the 6th (offset 5) is the bool.

    Code:
    ```
    // Get v2 non-indexed params from event registry
    static const std::string kEventSigV2 = "BridgeOutInitiated(address,uint256,uint256,uint256,uint256,bytes32,bool)";
    auto params_v2 = eth::cli::event_registry().params_for(kEventSigV2);
    // Filter to non-indexed only
    std::vector<eth::abi::AbiParam> non_indexed_params;
    for (const auto& p : params_v2) { if (!p.indexed) { non_indexed_params.push_back(p); } }
    // Decode
    auto decoded = eth::abi::decode_log_data(rpc_log.data, non_indexed_params);
    if (!decoded || decoded->size() < 6) {
        logger->warn("CatchUpScan v2: failed to decode log data"); continue;
    }
    const auto& x_bytes = std::get<eth::codec::Hash256>((*decoded)[4]); // 5th non-indexed = bytes32 X
    bool destination_y_odd = std::get<bool>((*decoded)[5]);             // 6th non-indexed = bool
    ```

    **Step 2 — Decompress with parity:**
    ```
    auto dest_opt = eth::DecompressXOnlyPubkey(x_bytes, destination_y_odd);
    if (!dest_opt) {
        logger->warn("CatchUpScan v2: X-only decompression failed for tx {}", tx_hash_hex);
        ++total_skipped;
        continue;
    }
    std::string destination = std::move(*dest_opt);
    ```

    `transaction_manager_->MintFunds(0, tx_hash_hex, std::to_string(chain_entry.chain_id), dev_config_.TokenID, destination)`

    **For v1 logs:** Keep the existing bare-bones MintFunds call unchanged (empty destination retained).

    Do NOT add sleep_for. Do NOT change v1 processing. Maintain exception safety (MintFunds is in a try/catch block).
