Add an algorithmic promotion rule inside the existing `ApplyVoteEffects` so a REGULAR validator that accumulates enough reputation (weight) with low penalty is promoted to FULL. This plan is logically independent of Plan 02's tally logic (D-08: promotion operates on weight, the tally reads weight) but serialized in Wave 3 because both plans edit `ValidatorRegistry.{hpp,cpp}`.
