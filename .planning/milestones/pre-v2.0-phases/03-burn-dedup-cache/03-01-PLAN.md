Fix 1 (D-01, D-02) — Add burn tx hash to GetSlotKey() in Consensus.cpp.

Current slot key for MintV2 (line 2143-2154):
```
mint-v2:{chain_id}:{token_id}:{amount}:{dest_addr}
```

Two distinct burns with identical chain/token/amount/dest produce the same key, causing consensus slot collision. The fix appends the burn tx hash from the first consumed outpoint.

After line 2152 (`key += mint.utxo_params().outputs( 0 ).dest_addr();`), and before the closing `}` of the outputs_size check (line 2153), add the burn tx hash. The burn tx hash is sourced from `consumed_outpoints[0].tx_id_hash` in the UTXO commitment embedded in the NonceSubject, NOT from `mint.utxo_params().inputs()`.

Looking at the code flow: `nonce_payload.value().utxo_commitment().consumed_outpoints(0).tx_id_hash()` contains the burn tx hash (per D-02 and STATE.md: "burn tx hash flows from MintFunds -> MintTransactionV2 -> UTXO commitment -> consumed_outpoints[0].tx_id_hash").

After the dest_addr append, add:
```cpp
const auto &commitment = nonce_payload.value().utxo_commitment();
if ( commitment.consumed_outpoints_size() > 0 )
{
    key += kSlotSeparator;
    // Append hex-encoded burn tx hash for uniqueness
    const auto &burn_hash = commitment.consumed_outpoints( 0 ).tx_id_hash();
    for ( uint8_t byte : burn_hash )
    {
        static constexpr char kHexDigits[] = "0123456789abcdef";
        key += kHexDigits[( byte >> 4 ) & 0x0F];
        key += kHexDigits[byte & 0x0F];
    }
}
```

Also move the dest_addr append OUTSIDE the `if (outputs_size > 0)` guard — the key should always include dest_addr if available, and always include burn hash if available. The current structure appends dest_addr inside the outputs check; keep that structure but add burn hash after it.

if ( !ep.bridge_contract_address.empty() )
{
    bool log_matched = false;
    for ( const auto &log_entry : receipt->receipt.logs )
    {
        // Convert log_entry.address to hex for comparison
        std::string log_addr_hex = rlp::base::parse::hex_array_string( log_entry.address );
        if ( log_addr_hex == ep.bridge_contract_address &&
             !log_entry.topics.empty() &&
             rlp::base::parse::hex_array_string( log_entry.topics.front() ) == ep.event_topic0 )

                      source_reference.substr( 0, 10 ), ep.url );

    }
}
