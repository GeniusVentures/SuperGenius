# Phase 4 Plan 03: Slot Key Collision Resistance

## Objective

Verify end-to-end that the Phase 3 GetSlotKey collision-resistance fix works correctly: two distinct burns with identical chain/token/amount/dest must produce different consensus slot keys, allowing both mints to succeed.

## must_haves

- Two MintTokens calls with identical chain/token/amount/dest but different burn tx hashes
- Both mints succeed (slot keys are distinct — no collision in the same consensus slot)
- Indirect verification through node balance: final balance >= initial + 2 × mint_amount
- Test uses the 3-node BridgeE2ETest fixture

## Tasks
