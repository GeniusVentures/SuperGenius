# Phase 4 Plan 01: Test Infrastructure + Positive E2E

## Objective

Create the E2E test infrastructure for the EVM bridge burn-to-mint pipeline and implement the positive BurnToMintPipeline test. Build a 3-node GTest fixture following the `processing_multi_test.cpp` pattern, bootstrap nodes via PubSub AddPeers, and exercise the full pipeline: Sepolia burn via `cast send` → BridgeRelayer detection → MintTransactionV2 → UTXO consensus → minted tokens in recipient's UTXO set.

## must_haves

- Three-node BridgeE2ETest fixture with separate DevConfig per node
- PubSub AddPeers bootstrap pattern (follows processing_multi_test.cpp)
- Three-guard skip logic: RUN_E2E_BRIDGE env var, PRIVATE_KEY env var, cast binary presence
- BurnToMintPipeline test: cast send burn on Sepolia, MintTokens with outcome assertions, UTXO polling with wait_condition
- CMake target bridge_e2e_test wired into test/src/CMakeLists.txt
- Build passes cleanly, test skips without env vars
